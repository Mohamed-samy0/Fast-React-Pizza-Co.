A modern, highly interactive, and responsive web application for ordering pizzas. This project goes beyond the standard implementation by introducing a custom UI redesign, seamless Dark Mode integration, and buttery-smooth animations.

## ✨ Key Features

* **Advanced Routing & Data Fetching:** Utilizes React Router's modern `loaders` and `actions` for fetching menu data and submitting orders before component rendering, eliminating loading spinners where possible.
* **Robust State Management:** Manages complex global state (like the user's cart and quantities) seamlessly using **Redux Toolkit**.
* **Custom Visual Identity & UI/UX:** A tailored design system moving away from default templates, providing a premium feel.
* **🌙 Seamless Dark Mode:** A fully integrated dark theme with an interactive toggle, ensuring accessibility and visual comfort.
* **✨ Fluid Animations:** Integrates `Framer Motion` for sophisticated staggered list animations, spring-based UI reveals, and satisfying button interactions.
* **Geolocation Integration:** Automatically fetches the user's current GPS location and reverse-geocodes it into a readable delivery address.

## 🛠️ Tech Stack

* **Frontend Framework:** React.js (Vite)
* **Routing:** React Router v6
* **State Management:** Redux Toolkit
* **Styling:** Tailwind CSS v4
* **Animations:** Framer Motion
* **Deployment:** https://fast-react-pizza-co-olive.vercel.app/

## 🚀 Getting Started

Follow these steps to run the project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Mohamed-samy0/Fast-React-Pizza-Co.
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd fast-react-pizza-co
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Start the development server:**
    ```bash
    npm run dev
    ```
